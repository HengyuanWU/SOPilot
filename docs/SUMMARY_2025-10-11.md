## 技术要点

### 架构层次

```
┌─────────────────────────────────────────┐
│         Workflow Layer (工作流层)         │
│  book_graph_node: 统一调度整书合并         │
│  - 在所有 section 完成后执行              │
│  - 调用 BookMerger.merge_book() 1次      │
└──────────────┬──────────────────────────┘
               │
┌──────────────▼──────────────────────────┐
│       Pipeline Layer (流水线层)           │
│  KGPipeline.run(): 处理单个 section       │
│  - 抽取、规范化、链接、ID生成              │
│  - 写入 Section Scope                   │
│  - 不调用 merge_book()                  │
└──────────────┬──────────────────────────┘
               │
┌──────────────▼──────────────────────────┐
│        Storage Layer (存储层)            │
│  - Section Scope: scope=section_id      │
│  - Book Scope: scope=book_id            │
│  - 两种 scope 互不干扰                   │
└─────────────────────────────────────────┘
```

### 核心规范

1. **职责分离**：
   - Pipeline：只负责 Section Scope
   - Workflow：负责 Book Scope 调度

2. **调用时机**：
   - `write_section()`：每个 section 调用 1 次
   - `merge_book()`：所有 section 完成后调用 1 次

3. **幂等性**：
   - Section 写入：幂等（MERGE）
   - Book 合并：先删除旧关系再写入
